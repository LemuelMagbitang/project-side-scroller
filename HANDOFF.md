# GitHub Upload Handoff

1. Unzip the prototype.
2. Upload the contents into `LemuelMagbitang/project-side-scroller`.
3. Keep the directory layout intact initially.
4. Run `npm install`.
5. Run `npm run dev` to preview it.
6. Run `npm run build` before committing.

Replace the sample artwork later under `public/assets/artworks/`.

The prototype already contains technical asset boundaries and a UV checker. See `ASSET_GUIDE.md`.

The public gallery-entry pattern is:

```text
https://your-domain.example/#gallery/memory-archive
```

The current prototype uses sample SVGs so it is easy to inspect and edit. Production artwork should be stored as optimized derivatives generated by an upload/CMS pipeline.
